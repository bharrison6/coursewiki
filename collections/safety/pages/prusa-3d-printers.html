3D printers: Category 1 in the Rapid Prototyping Center

These printers build parts from filament, layer by layer. See [[3d-printing-from-cad]] for preparing a model and [[3d-printing-fdm]] for the printing process.

Category 1 in the [[rpc-lab-equipment|Rapid Prototyping Center]]. Use [[equipment-categories]] for permission and supervision. General checks and protective equipment are in [[equipment-operating-procedure]] and [[ppe]].

Get the project and material approved before printing

In our labs, a DET faculty member must approve a 3D-printing project before it starts. A project assigned by DET faculty needs no separate project approval, but must stay within its own guidelines and all RPC rules.

For approval, explain what the item is, where its design came from, how it will be made, the material amount and source, and its intended use; supply the digital file through the instructor's designated channel.

  • No personal material without prior approval.
  • No weapons, weapon-like items, weapon components, ammunition, dangerous materials or drug paraphernalia.
  • No commercial use. Class projects take priority over personal projects.

Slice for the selected printer, then check it in person

  1. In PrusaSlicer, arrange and orient the model. Select the printer and filament, and set supports, infill and brim as needed. Slice, review the preview, material use and estimated time, then export the .gcode or .bgcode file.
  2. Use the lab's private job-identification instructions to name the file. In Prusa Connect, select a printer matching the type used when slicing.
  3. Check that printer's queue before uploading the file. In our labs, talk with the uploader before deleting a named job you think is no longer needed.
  4. Upload the file to the selected printer's dashboard, or use the guide's Send to Connect workflow from PrusaSlicer.

Before choosing Set Ready and Print Now, go to the machine and check:

  • The build plate is clear.
  • The loaded filament type matches the sliced file.
  • There is enough filament for the job.

If you are unsure the machine is ready, choose Add to print queue and check it before setting it ready later.

Hot surfaces and moving parts remain hazards during remote printing

The nozzle and heated bed can burn, including after motion stops. Let them cool before handling the finished print or build plate. Keep hands and tools out of the printer's moving area; use [[machine-hazards]] for the general movement and isolation rules. See Prusa's hot-part precautions for further reading, not permission to service lab equipment.

The lab guide uses Prusa Connect or its app to monitor progress. A remote status display does not replace the physical readiness check. Set Ready can release the next queued job, so use it only after checking the machine and clearing the work area.

When your print is finished and safe to handle, remove it, check the plate and material again, and set the printer ready for the next job. Remove scrap and purged filament, return tools and leave the work area tidy.

Report jams and faults; do not repair the printer yourself

In our labs, report jams, malfunctions and other technical problems to DET faculty. Do not try to fix equipment yourself. Stop a failing print using the controls covered in your training, and do not set a faulty printer ready for another job.

The student guide permits resetting an offline printer only when it is not currently in use. If you cannot establish that, or if a fault remains, report it rather than repeatedly resetting. Use [[conduct-and-emergency]] for an injury or emergency.
