Explore Types of AI

Compare written rules, a learned value table and a neural network on one tic-tac-toe board, then inspect the network's actual weights. Separate three questions people mix up: how a model is built, how it was trained, and what job it does — the last one linked to Hugging Face's own catalogue of model types.

The activity runs in your browser without an AI service. Use its Guide button for instructions and Settings for presenter notes, presentation mode and reset. Open it full screen when you want more room.

Learning path

  • Symbolic AI (GOFAI). Eight rules a person wrote. It never learns, and an exhaustive search still finds no losing line.
  • Value table. One score per position, learned from game outcomes. Train it until the search can call it unbeatable.
  • Neural Network. Shared weights fitted to the table's frozen scores, with error measured on positions kept out of training.
  • Other architectures & training methods. The wider map: trees, ensembles, SVMs and the rest, and which of 1a–1c used which training method.
  • Model types. What a model does rather than how it is built — Hugging Face's own by-task catalogue, with a link to real models of each type.
