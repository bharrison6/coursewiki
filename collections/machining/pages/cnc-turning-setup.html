Read X as a size and Z as a position along the spindle

Start with [[cnc-control-fundamentals]] for how CNC works and [[lathe-operations]] for the cuts a lathe makes. Here the work rotates and the ordinary turning tool moves in the XZ plane. Z runs along the spindle; positive Z is away from the headstock in the basic arrangement shown. X moves radially, even when its displayed value is a diameter. A slant bed or rear turret changes the view, so check the machine's axis diagram.

Confirm diameter or radius programming before reading an X value. For a 28 mm diameter, diameter mode uses X28 and radius mode uses X14. Moving from X28 to X24 in diameter mode removes 2 mm radially. Z is not halved. Confirm incremental and arc-centre conventions separately.

[[img:cnc-turning/axes.svg|Lathe side view: work zero is at the face on the spindle centreline. Positive Z points away from the headstock; X28 in diameter mode represents a surface 14 mm from the centreline.]]

Use [[absolute-and-incremental-positioning]] for coordinate arithmetic. On many Fanuc-style lathes X/Z are absolute endpoints and U/W are increments; G90 can be a turning cycle. Do not paste a mill's G90/G91 startup into a lathe program.

Practice lathe X commands

The tool arrangement determines how the next cutter reaches the work

A turret indexes a selected tool station into working position. Gang tooling mounts several tools on a slide; moving the slide brings the selected tool into position without turret indexing. Each tool still needs the correct offsets and a checked approach path.

Live tooling powers a rotating cutter on the lathe for operations such as drilling or milling. A C axis controls the spindle's angular position, allowing the work to be indexed or rotated under position control. These are options, not features of every CNC lathe. Some machines also add a Y axis. Live-tool and spindle-mode commands belong to the machine's manual.

Why an extra axis changes the work a turning center can do

Ordinary turning produces surfaces around the spindle axis. A powered tool plus controlled work angle can reach features at selected angular positions. See the Haas options programming reference for one manufacturer's C-axis implementation.

Match the workholding and automation to the part

  • A chuck grips with jaws. A self-centering chuck moves its jaws together; independent jaws permit individual adjustment. Jaw style and setup determine which shapes can be held.
  • A collet closes around a matching stock size and shape. Its useful size range depends on the collet design.
  • A tailstock center supports the free end of suitable work. It does not replace the chuck or collet that drives the work.
  • A bar feeder advances bar stock for successive parts. A parts catcher receives a separated part. Their timing and interlocks are machine-specific; neither is assumed in an ordinary two-axis program.

For operating requirements use the Safety collection and [[cnc-program-proving]]. No particular shop machine or installed option is assumed here.

Locate the part face once, then locate each tool relative to it

Use [[cnc-axes-and-offsets]] for machine zero, work zero and the general offset relationship. On a lathe, a common part datum is Z0 at the finished face and X0 on the spindle centreline. Establish the Z work shift using the control's documented reference-tool, probe or touch-off method. Allow for any material still to be faced away.

For X touch-off, the reference is a measured diameter. In a trial-cut method, a tool cuts a short cylindrical surface and that diameter is measured; the control's measurement function uses the known size to establish that tool's X geometry. Use the manual's procedure for the actual machine, including which table receives the value. Do not enter the measured diameter as though it were automatically the raw geometry-offset value.

Check whether an X wear entry is interpreted radially or diametrally, its sign, and whether the control adds to or replaces the existing value. A work-offset change affects the shared datum; a tool correction addresses one tool. Selecting G54 does not measure or store a new zero. G53 does not erase the offset table.
