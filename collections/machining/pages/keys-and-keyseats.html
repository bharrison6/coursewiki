A key joins the shaft slot to the hub slot to transmit torque

A key is a separate piece fitted between a shaft and the bore of a hub, such as a pulley or gear. Contact between the key and slot faces transfers turning force. Here, keyseat means the recess in the shaft and keyway means the matching slot in the hub. Other references sometimes use keyway for both; always identify which part is being cut.

The key does not by itself define how the hub is held against movement along the shaft. Check the assembly drawing for axial retention as well as torque transmission.

Identify the key by its cross-section and seating shape

KeyRecognizing feature
Square parallel keyEqual width and height in cross-section; uniform section along its working length.
Rectangular parallel keyUnequal width and height; uniform section along its working length.
Woodruff keyA segment of a disk, with a curved bottom seated in a matching circular recess in the shaft.
Gib-head keyA tapered key with a projecting head that provides a place to engage it for removal.

For a parallel key, the side fit controls how the turning load is carried. Excessive side clearance permits movement; an overly tight fit can prevent assembly. Verify the specified top clearance too. A tapered key has a different seating action, so do not apply a parallel-key fit rule to it.

Use the drawing's key designation, dimensions and tolerances. Do not choose a key size from shaft diameter alone or assume that half the key height belongs in each part.

Public reference for key forms

Engineering Institute of Technology, Fundamentals of Mechanical Engineering introduces keys, keyways and the common key types in its keys section. No standard size table or shaft-to-key size rule is reproduced here.

Practice identifying keys

Mill a shaft keyseat with the cutter that matches its end and bottom shape

An end mill can make a straight, flat-bottom shaft keyseat that ends within the shaft's length. Its diameter leaves rounded ends in plan view; confirm that the key and drawing allow that shape. Use a permitted entry method for the selected cutter.

A Woodruff keyseat cutter is a disk-shaped cutter on a shank. Its diameter forms the curved recess for a Woodruff key and its cutting width establishes the slot width. Match both dimensions to the required recess. Not every tool sold as a keyseat cutter is the correct tool for every key.

  1. Read the keyseat's width, depth, length or cutter diameter, and axial location from the drawing.
  2. Support and secure the shaft against rotation and displacement. Use [[milling-workholding]] for the setup.
  3. Align the shaft axis with the intended machine travel and locate its centerline using [[mill-indicating-and-zero]]. Set the cutter's cutting plane or path on that centerline, with the specified axial location and depth reference.
  4. Choose the tool and entry method with [[milling-cutter-selection]] and plan the cut with [[milling-operations]]. Cut to the planned allowance, measure, then finish to the required dimensions.

Review [[equipment-operating-procedure]] and [[machine-hazards|mill hazards]] in the safety collection before operation.

Why cutter selection includes more than width

Reach, neck clearance and tooth arrangement affect access and cutting behavior. See Harvey Performance's keyseat cutter considerations. A nominal tool width does not certify the width of the finished slot.

Broach a through hub keyway; consider slotting when the geometry needs it

A conventional keyway broach and guide bushing are useful for a straight keyway through a hub bore. See [[broaching]] for the pass sequence. The same arrangement does not make a closed-end keyseat on the outside of a shaft.

Shaping or slotting uses a reciprocating single-point tool to remove material in successive strokes. A suitable internal slotting setup can make a hub keyway when a through broach is unsuitable. Blind work still needs a planned tool runout and chip space; the method must fit the actual geometry.

Practice choosing a method

Check width, depth and location before using assembly as a fit check

  • Clean the feature and remove burrs without rounding the functional edges.
  • Check width at several accessible positions using a suitable slot gauge, gauge blocks or measuring contacts. Select a tool with enough access and resolution for the tolerance; see [[measurement-tools]].
  • Measure depth from the drawing's stated reference. A depth instrument needs a stable reference bridge or fixture on a round shaft; resting it arbitrarily on the curved surface changes the result.
  • For a hub, establish the specified bore-to-keyway measurement with an appropriate internal/keyway gauge or fixture. A reading across the bore and slot includes the bore dimension; it is not automatically the radial slot depth.
  • Check length, axial position and centerline location. Compare actual measurements with the drawing limits.
  • Check the specified key fit and assembly clearance. Investigate interference or unwanted movement instead of forcing the assembly together.

A key that enters the slot is a useful functional check, but it does not prove depth, location or dimensional compliance.
