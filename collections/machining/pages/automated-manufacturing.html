NC and CNC put machining motions under program control

Numerical control (NC) directs machine actions using coded instructions. Computer numerical control (CNC) uses a computer-based controller to execute those instructions. This is a base for automation, not a promise that loading, inspection and fault recovery are automatic too.

Programs still depend on correct tools, work location, offsets and a verified setup. See [[gcode-and-toolpaths]] and [[cnc-control-fundamentals]] for the controls and program details.

Tool changers and pallet changers automate different waits

An automatic tool changer exchanges cutting tools so a program can perform several operations. Correct tool identification, dimensions and available tool life remain essential.

A pallet changer exchanges work carriers. In a suitable system, one pallet can be loaded at a designated station while another is being machined. The pallet locates the fixture; the fixture locates the part. Dirt at either interface can undo the expected repeatability.

Repeatable [[jigs-and-fixtures|fixturing]] and planned [[shop-inspection|inspection]] are part of the automation system, not tasks that disappear after a changer is installed.

A manufacturing cell coordinates machines and handling

A flexible manufacturing cell combines machining and handling resources arranged to produce a planned family of parts. Flexibility comes from suitable programs, tools, fixtures and scheduling; it does not mean any part can be run without preparation.

A loading robot uses a programmed manipulator and a gripping device to transfer parts between defined positions. The cell must confirm conditions such as part presence, clamp state and machine readiness before the next action. A robot's repeatable motion does not compensate for a wrongly seated part.

Cell, system and integration describe different scopes

A flexible manufacturing system may coordinate multiple machines or cells with material handling and scheduling. Computer-integrated manufacturing is the broader idea of connecting manufacturing information and activities. These terms overlap in use, but are not interchangeable names for one machine configuration.

Lights-out production requires a plan for faults and variation

Lights-out machining means planned operation without an operator continuously attending the machines. It relies on a validated process, sufficient material and tool life, dependable chip and coolant management, and a defined response to faults.

Monitoring may detect tool breakage, missing parts or measurement trends, but only for conditions the system is designed to detect. Automatic compensation and inspection of every part are options, not universal features of automation. Decide what is measured, what stops production and how affected parts are contained.

Unattended operation is a system-level decision under the applicable equipment and facility procedures. These concepts are not authorization to leave a machine running unattended or enter an automated cell. A stopped cycle alone does not establish safe access.
