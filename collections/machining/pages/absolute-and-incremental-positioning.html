G90 gives a destination; G91 gives a signed change

In common milling usage, G90 makes axis values absolute coordinates in the active coordinate system. G91 makes them signed changes from the current position. Neither command moves an axis by itself. Units and work offsets still matter.

Increment = next position − current position. Reverse the calculation with next position = current position + increment. Keep a separate running total for every axis.

For an ordinary G00/G01 move, an omitted axis stays in place. In G90, X0 requests X zero; in G91, X0 requests zero X movement. Do not reuse an omitted incremental value from the preceding block.

These G90/G91 meanings must not be assumed on every lathe. Some turning controls use X/Z for absolute and U/W for incremental coordinates, and use G90 for a turning cycle. Check the control before translating a mill program to a lathe.

One path can be written as points or as moves

Start at A = (6,4) mm. Visit B = (26,4), C = (26,19), then D = (11,19). Z is unchanged; these are coordinate exercises with no cutting setup implied.

Check the conversion in both directions

Subtract endpoints: (26−6,4−4) = (20,0); (26−26,19−4) = (0,15); (11−26,19−19) = (−15,0). Add those changes to A: (6+20+0−15,4+0+15+0) = (11,19). The net move is (5,15), not the final absolute position.
