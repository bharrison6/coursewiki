Choose the model and sheet settings before placing views

Start with the intended part or assembly and confirm its configuration or version: the selected design variant or saved design state. A drawing of the wrong variant can look convincing and still describe the wrong product. See [[cad-files-and-documents]] and [[cad-history-and-sharing]].

A drawing template supplies starting settings. A sheet format supplies the border and title-block layout. CAD systems package these differently, so inspect the resulting sheet: size, units, projection method, scale, and dimension style all matter.

Use the workflow below as a sequence of tasks. Interface names vary by product and release; these are generic descriptions rather than menu instructions for SOLIDWORKS or Onshape.

Place a base view, then derive aligned projected views

Insert a base view from the model, choosing an orientation that communicates the shape clearly. Create projected views from that parent view, maintaining the required alignment and projection arrangement. Leave room for dimensions and notes.

[[img:engineering-graphics/drawings-in-design/model-to-views.svg|A rectangular block model supplies a drawing with a front base view, aligned top projected view above, and right projected view beside it in third-angle arrangement. The front and top share width, and front and right share height.]]

The figure uses third-angle placement only as an example. Follow the drawing's declared projection method. Choose enough views to define the shape; three views are not a requirement for every part. Use [[choosing-drawing-views]], [[section-views]], and [[auxiliary-and-detail-views]] when ordinary views do not explain a feature clearly.

Distinguish dimensions that control geometry from dimensions that report it

A driving model dimension controls geometry, such as the length of an extrusion. A dimension created by selecting drawing geometry usually reports that geometry. Changing a displayed label is not a sound way to change the part.

Some CAD workflows import model dimensions into drawings and allow linked edits to affect the model. Check the dimension's type and behavior before editing. Do not assume that all drawing dimensions are editable model controls, or that all are independent annotations.

Select dimensions to communicate manufacturing and inspection requirements, not merely every value used while modeling. Add needed tolerances, material information, and feature notes; CAD does not infer all design requirements from shape. Use [[choosing-dimensions]] and [[dimension-anatomy-and-placement]] for the dimensioning method.

Update linked views and inspect the sheet before release

Associativity is the connection between a model and the drawing information derived from it. When referenced geometry changes, linked views and dimensions can update to reflect it. Depending on the CAD system, update settings, and referenced version, an explicit update or reference change may be needed.

An update is not a completed review. Deleted or replaced edges can leave dimensions detached from their intended features. Notes can become obsolete. A previously exported PDF stays a snapshot; generate and check a new export after approved changes.

  • Confirm the referenced model, variant, and version, then update or rebuild the drawing as needed.
  • Inspect every affected view for the intended geometry, alignment, and readable line display.
  • Resolve detached dimensions and check that each dimension still refers to the intended feature.
  • Review units, view scales, material, tolerances, and notes for completeness and conflicts.
  • Complete the title block and required revision information; obtain the required review.
  • Export the approved sheets and inspect the actual output for missing views, clipped text, and readability.

See [[working-drawings-and-title-blocks]] for identifying the released information.

Find the commands in your CAD version

Start with the vendor's Onshape drawing help or SOLIDWORKS Help, selecting your installed release where applicable. Consult its drawing creation, projected view, dimension, and update topics. Command sequences are intentionally kept generic here.
