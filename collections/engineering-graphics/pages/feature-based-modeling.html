Build the main shape, then add and remove material

A parametric model stores instructions for building a shape. Dimensions and relationships are inputs; the solid is the result. Change an input and rebuild to see the result update.

The base feature creates the initial solid. Later features add material, remove material, or modify faces and edges. For a simple spacer, start with its main cross-section and extrude it. For a stepped round knob, a revolved section may describe the main shape more directly. There is often more than one valid feature sequence.

A body is a connected piece of solid geometry. A SOLIDWORKS part file can contain multiple bodies. An Onshape Part Studio can create multiple parts from a shared feature list. Neither arrangement, by itself, defines assembly motion or assembly relationships.

Start with sketch dimensions and relations in the Engineering Graphics collection. Then choose [[extrude-and-revolve|extrude or revolve]] for a straight or rotational shape, or [[sweeps-and-lofts|sweep or loft]] for a path or a changing cross-section.

The feature tree records a build sequence and its dependencies

Read the tree from the base feature toward the end. A feature that supplies a sketch, face, edge, or other reference is a parent; a feature that uses that reference is a child. A child can depend on more than one parent. Being later in the list does not, by itself, make a feature a direct child of every earlier feature.

For example: a plate extrusion supplies a top face for a hole-position sketch. A hole feature uses that sketch. A pattern uses that hole as its seed. Delete the hole and the pattern loses its seed; delete the plate and the sketch loses its support as well. Inspect the deletion dialog before accepting dependent deletions.

Rename features for their purpose, such as Main plate, Locating hole, and Hole row. Renaming a feature in the tree is different from renaming a referenced part file. File references need their own reference-aware workflow.

Why a small edit can break a later feature

A face or edge can disappear when the shape changes. A sketch attached to that face, or a fillet attached to that edge, then has a missing reference. Repair the first failed feature before chasing errors farther down the tree. Reordering is constrained by dependencies: a feature cannot use geometry that has not yet been created.

Rollback lets you inspect an earlier stage without deleting later work

Move the rollback bar above later features to inspect or edit an earlier stage. Return it to the end when checking the completed part. Rollback is a temporary stopping point in regeneration. Suppression instead leaves a selected feature in the tree but excludes it from the active model; dependent features may also be affected. Hiding changes visibility, not the solid's definition.

  • Find the earliest feature that fails or produces the wrong shape.
  • Roll back to inspect the geometry and references available at that point.
  • Edit the sketch for its dimensions or relations; edit the feature for its operation, depth, direction, or selected references.
  • Roll forward to the end, rebuild, and inspect the downstream results.
Vendor help for history and rollback

See SOLIDWORKS: Rollback Bar, Suppress and Unsuppress Features, and Onshape: Feature and Part Lists. Onshape document history records editing activity; moving a Part Studio rollback bar is not restoring an older document version.

Choose references that express what must stay aligned

A reference plane locates a sketch or defines symmetry. A reference axis supplies a direction or center of rotation. Neither adds material. Use the origin and default planes when they express the design; add offset, angled, or mid-planes when needed. Reference geometry can also have parents.

Design intent is what should stay true when dimensions change. A centered plate should grow equally on both sides of its center plane. A hole required to pass through the plate should remain through when the plate gets thicker. A row of identical holes should share one seed definition and a spacing rule.

Put major shape and functional references early. Add small edge treatments later when they are finishing details. This is a useful starting order, not a rule that every fillet must be last: a large blend that defines the main shape may belong before shelling or other features.

Fewest features is not always the best model

A single complicated sketch can hide many unrelated decisions. Several named features may be easier to edit. Count features only after stating which operations are allowed and what the model must do when changed. A feature tree is also not a manufacturing operation sheet: a CAD cut does not specify tooling or setups.

Check units, bodies, material, and mass after a change

Assign the intended material or density before relying on mass. A surface color is not evidence that density is correct. For a uniform solid, mass = density × volume. Compare volume with a simple estimate, and inspect unexpected mass or center-of-mass changes.

A fresh example: a solid rectangular spacer measuring 30 × 20 × 8 mm has a volume of 4,800 mm³ = 4.8 cm³. With an assumed density of 2.50 g/cm³, its mass is 12.0 g. These are practice values, not a material specification. A hole should reduce that mass if the same body and density remain selected.

  • Confirm the document units and overall dimensions.
  • Confirm the expected body or part count and the scope of each add or cut.
  • Change one important dimension, rebuild, and check the intended relationships.
  • Check material assignment, selected bodies, and any mass overrides before trusting the result.

Mass properties are a check, not proof of a correct part

Different shapes can have the same volume and mass. Check the geometry as well. Onshape omits parts without assigned material from density-based calculations; inspect its notices and selection. See Onshape: Mass Properties Tool and SOLIDWORKS: Bodies and Features of Multibody Parts.
