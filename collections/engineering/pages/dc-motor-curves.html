More load torque means less speed on this curve

This model approximates a permanent-magnet DC motor at a fixed supply voltage with a straight line between two endpoints. Stall torque is the torque at zero speed. No-load speed is the speed at zero external shaft load. It is not a universal curve for induction motors, steppers, or regulated drives.

Let Ts be stall torque, n0 no-load speed, and T the constant resisting load torque. The steady operating point is where motor torque equals load torque:

n = n0(1 − T/Ts).

This is an assumed linear approximation, not a measured motor rating. It omits acceleration, current limiting, temperature changes, and supply voltage drop. At stall it predicts zero shaft power, not zero electrical input. A stall rating is not a continuous operating rating.

Manufacturer basis for the straight line

maxon's Motor Data and Operating Ranges, p. 10, states: Enhancing the load torque leads to a linear reduction of the speed. It identifies no-load speed and stall torque as the endpoints and specifies fixed applied voltage.

Explore the load point and the peak-power point

Predict first: a model motor has 0.8 N·m stall torque and 3,000 rpm no-load speed. A constant load asks for 0.2 N·m. Does the motor run above or below half speed?

[[img:electrical-systems/dc-motor-curve.svg|Normalized torque falls from one at stall to zero at no-load speed. Normalized output power peaks at half no-load speed. A load of one-quarter stall torque operates at three-quarters no-load speed.]]

Static example: n = 3,000(1 − 0.2/0.8) = 2,250 rpm. Angular speed is 2,250 × 2π/60 = 235.6 rad/s, so output power is 47.12 W. Peak power is 62.83 W at 1,500 rpm and 0.4 N·m.

Ideal motor and constant load

The solid line is torque / stall torque; the dashed curve is power / peak power. The circle marks load torque; the diamond marks output power. The square marks peak power.

Peak power is halfway, not at either endpoint

Use P = Tω, with torque in N·m and angular speed in rad/s. Convert rpm using ω = 2πn/60. The definitions and units are on [[power-and-efficiency]] and [[angular-motion]].

At stall there is torque but no speed. At no load there is speed but no external load torque. Both endpoints therefore have zero shaft output power. Between them, torque times speed reaches a maximum.

Derive the halfway result from the straight line

Put x = n/n0. Then T = Ts(1 − x), so P = Tsω0x(1 − x). Since x(1 − x) = 1/4 − (x − 1/2)2, the largest value is 1/4 at x = 1/2. Thus peak power = Tsω0/4, at half no-load speed and half stall torque. The two endpoint maxima cannot occur at the same time.

Manufacturer check on peak power

Portescap's Brush DC Motor Basics, p. 1, point 4, places maximum mechanical power at half the stall torque. On the linear curve, this also means half no-load speed, as derived above.

Peak efficiency needs electrical input as well as shaft output

Efficiency is output power divided by input power. Peak output power and peak efficiency answer different questions. The torque-speed line alone does not give electrical input or losses, so this explorer deliberately does not calculate efficiency.

For the brushed coreless DC motors described by Portescap, peak efficiency occurs at a lighter load and higher speed than peak output power. Its exact position needs loss or current data. No external load means no useful shaft output, even though a real motor draws current to overcome its internal losses. Consult the actual motor's efficiency and continuous-operation data before selecting a load point.

Manufacturer basis for the efficiency comparison

Portescap's Brush DC Motor Basics, p. 1, point 3, states: The maximum efficiency is obtained at high speed. Its accompanying torque plot places the efficiency peak below the torque of peak power; the descending speed line therefore puts it at higher speed.

A gearbox changes the load seen by the motor

A gearbox can move the operating point by changing the torque demanded at the motor shaft for the same output load. Reduction trades output speed for output torque; it does not add power. Use [[gear-ratios]] for the ratio calculation, then bring the resulting motor-shaft torque back to this curve.

Real loads may demand different torque at different speeds. Their operating point is an intersection of a load curve and a motor curve. This explorer uses a constant load so that the first calculation stays visible.
