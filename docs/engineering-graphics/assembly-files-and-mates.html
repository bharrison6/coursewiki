Assembly Files and Mates

Keep component references intact and choose mates that locate parts while preserving their intended motion.

An assembly records which parts belong together and how they fit

An assembly records which parts belong together and how they fit

A part defines a component's shape. An assembly places instances of parts and subassemblies and records relationships between them. Two instances of one part can occupy different positions while using the same part definition.

In a file-based SOLIDWORKS assembly, the .SLDASM normally references external .SLDPRT and other assembly files. An assembly drawing references the assembly. Sending only the assembly file can leave the recipient without its components. Virtual components are an exception: their definitions can be stored inside the assembly.

Onshape organizes Part Studios, Assemblies, and Drawings as tabs in documents. Inserted instances reference their source definitions; a tab name is not a Windows filename. Share the document with the appropriate access and identify the intended version when a fixed design state matters.

Definitions, instances, and design changes

Changing a shared part definition can update several instances. Moving one instance in an assembly changes its placement, not the shape of every copy. A configuration can select a particular variant of a component; record the intended variant when sharing or drawing it.

Onshape: Sharing and Collaboration explains document access and permissions.

Rename and package files with their references; Checklist

Rename and package files with their references

Renaming or moving a component in ordinary File Explorer can leave an assembly looking for its old name or location. Use the CAD system's reference-aware rename or move workflow. Changing a display name in the tree is not necessarily changing the file name.

  • Save a recoverable copy before reorganizing an assembly's files.
  • Use the supported rename workflow, include affected assemblies and drawings, and save the referencing documents.
  • For file-based SOLIDWORKS sharing, use Pack and Go where available. Review the file list, drawing inclusion, library components, and destination.
  • Open the packaged assembly from its destination and inspect the resolved reference paths. Confirm it is not quietly loading parts from the original folders.
Vendor help for renaming and sharing

SOLIDWORKS: Renaming Components distinguishes display names from file names and explains updating references in closed documents. Saving an open assembly alone does not automatically repair every closed drawing. Availability differs for platform-connected installations.

SOLIDWORKS: Pack and Go Overview describes collecting related files into a folder or ZIP. Use your installed edition's help for the exact controls.

Ground a base, then count the motion you intend to keep

Ground a base, then count the motion you intend to keep

A free rigid component in three-dimensional space has six degrees of freedom (DOF): translation along three axes and rotation about three axes. A degree of freedom is an independent motion, not a count of arrows or mates.

Choose a base or housing as the reference. Fix it, or fully locate it to the assembly origin and planes. In SOLIDWORKS, insertion options include fixing only the first component, fixing inserted components, or leaving them floating. Check the actual state; do not assume that the first component is always fixed. Fixing a base away from the origin holds it there; it does not move it to the origin.

A lever should still rotate about its pivot. A cover should stay put. Fully locating every moving part would turn a mechanism into a rigid model.

Check the insertion setting

SOLIDWORKS: Insert Components documents the Fix / Float choices. Grounding the base and choosing the remaining joint motion are separate decisions.

Use geometric mates to describe the intended contact

Use geometric mates to describe the intended contact

Select the actual locating faces, axes, or reference planes. The same mate name can accept different geometry, so its effect depends on what you select. The diagrams below are schematic before/after comparisons, not complete constraints for whole assemblies.

Coincident
For two planar faces, put their supporting planes together. The faces can still slide in that plane and rotate about its normal. Coincident planes do not guarantee that finite faces overlap.
Concentric
Put two cylindrical axes on the same line. Without a rotation lock or other mates, a shaft can still slide along and rotate about that line.
Why subtracting one DOF per mate gives the wrong answer

For one free rigid part relative to a grounded part, a planar-face coincident mate leaves three DOF. A cylindrical-axis concentric mate leaves two. Adding a shoulder-face coincident mate perpendicular to that axis removes axial sliding and leaves one rotation. A redundant mate may remove no new freedom. Count the independent motions that survive each step.

See SOLIDWORKS: Types of Mates for supported selections. These geometric names are not a one-to-one map to Onshape commands.

Parallel and perpendicular mates set orientation

Parallel and perpendicular mates set orientation

Parallel keeps selected planes parallel without setting their separation. Perpendicular keeps selected planes at a right angle. Neither condition alone fully locates the part. These diagrams show the planes edge-on.

Distance, angle, and tangent mates control gaps and contact

Distance, angle, and tangent mates control gaps and contact

Distance sets a separation between selected entities. For parallel planar faces, use the normal gap, not a slanted edge length. Angle sets the angle between selected entities; check alignment and direction so the model uses the intended side of the angle.

Tangent keeps compatible curved and planar or curved surfaces touching tangentially. Tangency alone does not enforce rolling without slipping.

Choose a joint or mechanical relationship when motion is the point

Choose a joint or mechanical relationship when motion is the point

For a simple lever on a grounded pin, align the pivot axes and locate the lever axially. Leave rotation free. A hinge mate expresses this single rotational freedom directly. In Onshape, a Revolute mate serves that joint purpose; Cylindrical allows axial slide and spin, Slider allows one translation, and Fastened allows no relative motion. Mate connectors establish the joint frames.

A slot mate locates a pin or similar feature relative to a slot. Select free travel or a prescribed position to match the design; other motions depend on the selections and remaining mates. Onshape's Pin Slot mate allows rotation about the connector's Z axis and translation along its X axis. Set appropriate travel limits; it is not an identical set of SOLIDWORKS slot options.

A gear mate or gear relation couples rotations by a ratio. Locate the shafts first. The relation does not create teeth or prove they mesh without interference. Use Gear Ratios for the ratio calculation and Torque for the separate question of turning effort.

Compare vendor joint vocabulary

Onshape: Mates describes joint motion through mate connectors. SOLIDWORKS: Machine Design Tools introduces mechanical mates. SOLIDWORKS slot settings distinguish free, centered, distance, and percentage positions.

Build reusable parts and subassemblies with deliberate dependencies; Practice

Build reusable parts and subassemblies with deliberate dependencies

Bottom-up design starts with existing parts and brings them into an assembly. Top-down design starts with an overall layout or shared design references and develops parts around them. A mixed approach is common: use a shared layout for custom plates and insert purchased hardware.

A subassembly groups parts into a reusable unit. Give it a useful function, such as a pivot cartridge, rather than hiding unrelated parts in it. Check whether its internal joints are allowed to move at the parent level; a rigid subassembly can make a working joint appear locked.

Top-down references can keep mating holes aligned when the layout changes, but they also create dependencies. Keep the direction of those dependencies understandable and check them when copying or sharing the design.

What makes a feature top-down?

SOLIDWORKS: Top-Down Design explains how layout or other-component geometry controls a feature and creates external references. Merely editing a part while an assembly is visible does not by itself establish that dependency.

Use SOLIDWORKS Toolbox or Onshape Standard Content, where available, for standard hardware. Choose the standard, size, thread pitch, length, and material or grade deliberately. A visually similar bolt or an automatic size suggestion is not a completed fastener selection.

Library hardware still needs checking

Onshape: Standard Content explains insertion and sizing. SOLIDWORKS Toolbox is an add-in described in its machine-design overview. Check the resulting model and BOM properties rather than modeling every thread from scratch.
