Derive a related view: A base view is already linked to the intended model. You need an aligned adjacent view. What is the sound next step?

  1. Insert a second base view from the model and line it up by eye
  2. Stretch a copy of the base view
  3. Create a projected view from the base
Enter a number, then check it.
Show answer and reasoning

Choice 3. Deriving the projected view preserves the model relationship and intended alignment. A second independent base view shows correct geometry but is not tied to its neighbour, so its alignment and scale can drift when the sheet changes. Check its placement against the projection method.

Choice 1. A text override can misrepresent unchanged geometry. Use the model control and inspect the linked drawing dimensions after updating.
