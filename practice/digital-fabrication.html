Orient a bar for tension

A straight printed bar will be pulled along its length. Compare printing it standing on its end with printing its length parallel to the bed. Assume the same material and a sound print. Which is the better starting orientation, and why?

Self-check: write a reason before revealing. This response is not automatically graded or saved.

Show reasoning

Start with the length parallel to the bed. Printing upright puts the tension across the interfaces between layers, where separation is often easier. Laying the bar down allows paths within layers to run along its length. Actual strength still depends on material, paths, and bonding; test a representative part.

Separate an outline from a filled mark

An approved sheet must yield a rectangular label with a filled dark symbol on its face. Which operation belongs on the outside boundary, and which belongs on the filled symbol? Should a thin score line automatically use through-cut settings?

Self-check: write a reason before revealing. This response is not automatically graded or saved.

Show reasoning

Use a vector cutting path for the outside boundary and raster engraving for the filled symbol. A vector score follows a path but is intended to mark the surface, so it needs an appropriate scoring setup rather than through-cut settings. Verify the assignments in the job preview.

Compensate an outside width

A rectangular cutout must finish 30.00 mm wide. Assume a constant 0.18 mm kerf centered on the path, with no automatic compensation. What path-to-path width produces that finished outside width? Give millimeters to the nearest 0.01 mm.

Enter a number, then check it.
Show worked solution

Each path moves outward by 0.18 / 2 = 0.09 mm. Across both sides, 30.00 + 2 × 0.09 = 30.18 mm. Subtracting kerf would shrink the part further; adding only half the kerf would compensate only one edge.

Compensate an opening

A rectangular opening must finish 12.00 mm wide. Assume a constant 0.22 mm kerf centered on the path and no automatic compensation. What path-to-path width is needed? Give millimeters to the nearest 0.01 mm.

Enter a number, then check it.
Show worked solution

The waste is inside the opening. Move each path inward by 0.22 / 2 = 0.11 mm. The path width is 12.00 − 0.22 = 11.78 mm. Cutting removes half the kerf beyond each path and brings the finished opening back to 12.00 mm.

Choose a process for two shapes

Choose an initial process for (A) a flat cover of constant thickness with surface lettering and (B) a one-piece rounded grip whose cross section changes along its length. Approved sheet and printable materials both meet the stated service requirements. Explain a limitation of each choice.

Self-check: write a reason before revealing. This response is not automatically graded or saved.

Show reasoning

A: laser-cut and engrave the sheet; account for kerf, available thickness, and edge quality. B: print the grip; choose orientation for load and surface quality and check support access. A laser could make a grip from stacked profiles, but that changes the one-piece construction requirement. Neither process is automatically faster without estimating the actual jobs.

Separate slot clearance from kerf

A measured sheet edge is 3.02 mm thick. Its receiving slot needs 0.10 mm total clearance across the width. Assume a constant 0.20 mm kerf centered on the path and no automatic compensation. What path-to-path slot width produces the desired finished slot? Give millimeters to the nearest 0.01 mm. These are exercise values, not a recommended fit.

Enter a number, then check it.
Show worked solution

First choose the finished opening: 3.02 + 0.10 = 3.12 mm. Then compensate the opening's kerf: 3.12 − 0.20 = 2.92 mm. The cut enlarges this path width to 3.12 mm. Clearance is added once because the question gives total clearance, not clearance per side.
