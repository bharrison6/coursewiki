Reflect the load torque to the motor

Reflect load through a reduction: A 20-tooth motor gear drives a 40-tooth output gear through one mesh modeled at 90% efficiency. The output load torque is 0.600 N·m. What motor torque is required at a steady running point? Give four significant figures.

Enter a number, then check it.
Show worked solution

The reduction is i = 40/20 = 2. With stated running mesh efficiency η = 0.90, Tmotor = Tload/(iη) = 0.600/(2 × 0.90) = 0.3333 N·m. Using 0.300 N·m ignores the modeled loss.

Find the motor and output speeds

Find geared output speed: The motor has 0.800 N·m stall torque and 120 rpm no-load speed. It supplies the 0.3333 N·m reflected torque from the previous problem. Using the ideal linear motor curve and the 2:1 reduction, what is output speed?

nmotor = 120(1 − 0.3333/0.800) = 70.0 rpm. The 2:1 reduction gives noutput = 70.0/2 = 35.0 rpm. Dividing the 120 rpm no-load endpoint by two would ignore the loaded motor curve.

Find modeled output power

Find gearbox output power: The motor operates at 0.3333 N·m and 70.0 rpm. Find motor shaft power, then apply the stated 90% running mesh efficiency. Give output power in watts. You may use π = 3.14 and four-significant-figure intermediate values.

Pmotor = Tω = 0.3333 × 70.0 × 2π/60 = 2.443 W. Then Poutput = 0.90 × 2.443 = 2.199 W. Multiplying torque by rpm without converting to rad/s gives the wrong units and value.

Explain why output power changed

Explain the comparison: In the lesson example, direct output power is 1.885 W while geared output power is 2.199 W. Which explanation matches the model? 1 = the gearbox created power; 2 = both cases had equal motor shaft power; 3 = reflected torque moved the motor to a different speed and shaft-power point before mesh loss; 4 = the mesh was more than 100% efficient.

Enter a number, then check it.
Show worked solution

3. The reduction changes the motor torque required by the same output load. The motor therefore settles at a different speed and produces different shaft power. The stated mesh loss is then applied. This is not free power and does not claim equal electrical input.

Recognize a missing operating point

Compare direct overload with geared running: Keep the 0.800 N·m, 120 rpm motor and the 2:1, 90% reduction, but raise output load torque to 0.900 N·m. Direct drive has no forward steady operating point in this model. What geared output speed does the model give?

Show worked solution

The reflected motor torque is 0.900/(2 × 0.90) = 0.500 N·m. The motor curve gives 120(1 − 0.500/0.800) = 45.0 rpm. After the 2:1 reduction, output speed is 22.5 rpm. This steady-running point does not prove the system starts or runs continuously.
