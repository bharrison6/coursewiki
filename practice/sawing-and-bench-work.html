Blade selection and hand-tool decisions

Teeth across a quarter inch: A uniform 24 TPI blade crosses 0.250 in of continuous material along the tooth line. Estimate teeth engaged. Give one decimal place.

0.250 in × 24 teeth/in = 6.0 teeth. This is a spacing estimate; actual engagement changes as the blade moves.

Teeth across a decimal thickness: A uniform 18 TPI blade crosses 0.250 in of continuous material along the tooth line. Estimate teeth engaged to one decimal place.

Enter a number, then check it.
Show worked solution

0.250 × 18 = 4.5 teeth. Do not divide thickness by TPI; that does not count tooth spacings.

Convert thickness before using TPI: A uniform 12 TPI blade crosses 6.35 mm of continuous material. Use 25.4 mm = 1 in. Estimate teeth engaged to one decimal place.

Enter a number, then check it.
Show worked solution

6.35 ÷ 25.4 = 0.250 in. Then 0.250 × 12 = 3.0 teeth. Multiplying millimeters directly by teeth per inch mixes units.

Minimum calculated pitch: For 0.125 in of continuous contact, calculate the minimum TPI for an estimated three teeth. Give one decimal place. This asks for the mathematical threshold, not a catalog selection.

Enter a number, then check it.
Show worked solution

3 ÷ 0.125 = 24.0 TPI. Check: 0.125 × 24 = 3 teeth.

Select from available pitches: For this simplified exercise, the candidate uniform pitches are 10, 14, and 18 TPI. A continuous contact length is 0.200 in. Which is the coarsest candidate meeting the three-tooth estimate? Enter the TPI. Actual selection also needs the maker's chart.

Enter a number, then check it.
Show worked solution

3 ÷ 0.200 = 15 TPI minimum. The available choice is 18 TPI: 0.200 × 18 = 3.6 teeth. The tempting 14 TPI choice gives only 2.8.

Thin-wall tube versus solid bar: A thin-wall tube and a solid bar have the same outside diameter. Which selection approach fits the tube? Enter 1 or 2.
1: Count the whole outside diameter as solid engagement.
2: Use a tube/structural chart with wall thickness and overall size; expect finer teeth than for the solid bar.

Enter a number, then check it.
Show worked solution

2. The hollow center is not material. Engagement changes around the tube, so neither outside diameter alone nor a fixed two-wall sum describes the whole cut.

Chip space in soft material: A blade specification calls for widely spaced teeth, generous gullets, and a zero-rake form for chip clearance in a softer material. Which named form fits? Enter 1, 2, or 3.
1: Fine regular.
2: Skip.
3: Positive-rake hook.

Enter a number, then check it.
Show worked solution

2: skip. The generous chip space and zero-rake description identify the form. Final pitch still depends on section size.

Identify a positive-rake form: A maker recommends an aggressive positive-rake tooth form for a supported production cut. Which form does that describe? Enter 1, 2, or 3.
1: Regular.
2: Skip.
3: Hook.

Enter a number, then check it.
Show worked solution

3: hook. Positive rake describes the face angle. It does not establish pitch, set, or one universal rake angle.

Fine-pitch set for thin sections: For a thin section, a fine-pitch blade specification calls for groups of teeth that gradually change sideways displacement. Which set matches? Enter 1, 2, or 3.
1: Left-right-straight raker.
2: Wavy.
3: Left-right alternate.

Enter a number, then check it.
Show worked solution

2: wavy. Groups create the wave of set. Raker includes an unset tooth; alternate switches sides at each tooth. Set alone does not determine suitable TPI.

Hand hacksaw cutting direction: For a conventional push-cut hand hacksaw, which setup is correct? Enter 1 or 2.
1: Teeth away from the handle; pressure on the forward stroke, eased on return.
2: Teeth toward the handle; heavy pressure in both directions.

Enter a number, then check it.
Show worked solution

1. The teeth face the cutting stroke. This describes a conventional hand hacksaw, not a universal power-hacksaw stroke direction.

Choose a file for draw filing: A flat face needs light finishing by draw filing after rough shaping. Which is the better starting choice? Enter 1 or 2.
1: A coarse double-cut file chosen for rapid stock removal.
2: A suitable fine single-cut file, kept clean and flat.

Enter a number, then check it.
Show worked solution

2. A fine single-cut file suits controlled draw filing. Keep the file crosswise to the travel and avoid rocking across the face.

Choose a file for stock removal: An accessible flat steel edge needs substantial hand shaping before finishing. Which file is the better starting choice? Enter 1 or 2.
1: A suitable bastard-grade double-cut flat file.
2: A fine round file chosen for finishing a small round opening.

Enter a number, then check it.
Show worked solution

1. Match both shape and removal rate. Bastard describes coarseness; double-cut describes the crossing tooth pattern.

Respond to chips lodged in a file: A file begins leaving deep scratches, and chips are lodged between its teeth. What should happen next? Enter 1 or 2.
1: Increase pressure so the file forces the chips through.
2: Clear the teeth with a file card, then inspect the work and resume controlled filing.

Enter a number, then check it.
Show worked solution

2. This is pinning. Trapped chips can score the work; extra force does not restore a clean cutting surface.
