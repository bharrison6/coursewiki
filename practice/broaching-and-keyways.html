  3. Repeat without a shim to obtain the specified extra depth.

Option 2. The shim offsets the tool for the next cut. The prescribed stack belongs behind the broach, and setup checks repeat between passes.

Count first and shimmed passes. Invented planning model: the unshimmed pass reaches 1.0 mm radial depth. Each later pass, with one additional shim increment, adds 0.5 mm. How many total passes reach 2.5 mm? Include the first pass; round a fractional added-pass count upward. These are not tool settings.

Enter a number, then check it.
Show reasoning

1 + ceiling((2.5 − 1.0)/0.5) = 1 + 3 = 4 passes. Depths are 1.0, 1.5, 2.0 and 2.5 mm. Three counts only the added passes; five incorrectly divides the full target by the shim increment.

Round up, then check overshoot. Invented model: the first pass reaches 1.0 mm; each added shim increment gives 0.5 mm more depth on the next pass. What minimum total pass count reaches AT LEAST 2.2 mm? Round upward to a whole pass. This counting answer is not permission to exceed a drawing limit.

Enter a number, then check it.
Show reasoning

1 + ceiling((2.2 − 1.0)/0.5) = 1 + ceiling(2.4) = 4. Three passes reach only 2.0 mm. Four reach 2.5 mm, so this schedule is unsuitable if 2.2 mm is the maximum allowed depth.
